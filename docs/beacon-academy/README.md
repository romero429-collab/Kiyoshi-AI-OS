# Beacon Academy Corpus

This directory holds the **Beacon Academy / Kiyoshi Academy** markdown corpus synced from Google Drive (Kiyoshi Drive folder).

- Source: Google Drive (Kiyoshi project folder)
- Scope: markdown design docs only (architecture, crypto, economics, digital twin, colony extension, etc.)
- **Not** synced here: `.docx` biological-integration docs, videos, zip archives, images, and HTML — those remain on Drive for now

These files are reference material for the Academy civilization model that Kiyoshi Academy builds on. They are not runtime code.
