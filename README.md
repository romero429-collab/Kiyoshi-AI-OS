# Kiyoshi-AI-OS
Kiyoshi AI Operating System - Core deterministic modular engine for adaptive intelligent computation

## Phase 0 — Continuity Engine

A playable console lives in [`phase-0/`](./phase-0). It sits beside `docs/` and `src/`. It does not replace the kernel, and it does not claim the specification is implemented. Article IV still holds: no subsystem without specification, implementation, and a verification suite.

Kiyoshi does not assume that its representation of reality is reality. It continuously maintains the relationship between observation, representation, simulation, and action.

Surfaces: Console, Governor, Agency, Ground, Improve, Charter. Internally: Field (Iris stage, seven domains, keep/hold), Layers, Memory.

See [`phase-0/README.md`](./phase-0/README.md).
