# Phase 0 decisions that are not inside the pastes

The pastes are the multi-model thread. This file records what the build session did with them. It is not dialogue.

## Built, and on the branch

Playable console under `phase-0/`. Six surfaces in the nav: Console, Governor, Agency, Ground, Improve, Charter. Field (Iris stage, seven domains, primitives, envelopes, provenance, keep/hold), Layers, and Memory are reachable inside the console, not as extra nav items.

Loops that run, not lectures:

- Governor: mode selection → confidence → execution → monitoring → discrepancy → reassessment → hold, transfer, or veto. Modes are clarify, research, plan, execute, reflect. They are epistemologies, not speeds.
- Agency, when nobody supplies the next objective: Need → Intent → Authority → Risk → Mode → Plan → Action → Verify → Learn. Includes the refusal cases (vague intent, charter veto, charge proximity).
- Improve: observe → identify → modify an operational artifact → test → evaluate → retain. Not weights.
- Ground: claim, speak, yield. Scenarios include underspecified work, settled work (Grok and Gemini do not fuse), failure then adapt, one mind (Casey overflow), two eyes, and the chair.
- Iris stage: Reality, Simulation, Overlay, Swap, Neither. Costumes: chair, rock, ship, doorway, nothing. Walk-through-a-drawn-doorway is vetoed. Neither suspends perception; the system continues.

Charter in the playable catalog (`ARTICLES`) appends two lines the spec tree does not yet have:

- Article I: representation is not reality.
- Article VII: observed is not simulated; never silently promote.

`docs/governance/Kiyoshi_Constitution_v0.1-R.md` was not overwritten. Article VIII says amendments append. Doing it inside the playable catalog, not by replacing the spec, is that rule applied to the repo.

## Stack, as fixed by the thread and the code

Kiyoshi hardware abstraction → OS → Iris (perception / simulation) → Red Clover (coordination) → Air Sync (physical) → Blue Lotus (identity) → applications.

Seven domains: Physical (Air Sync), Biological (Anise / Cybercell), Computational (Kiyoshi Core), Intelligence (agents), Simulation (Iris), Network (Red Clover), Human/social (Blue Lotus).

Five primitives: state, entity, environment, representation, transition.

Continuity: Prior → Encounter → Perceive → Evidence → Interpret → Act → Consequence → Revise. Reality → Kiyoshi → Iris → Kiyoshi → Reality. Simulation is a laboratory.
