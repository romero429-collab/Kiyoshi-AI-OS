A system coordinating multiple intelligences according to the situation.

Research mode

Planning mode
→ another system decomposes the problem and develops a course of action.

Execution mode
→ an agent with the appropriate tools actually performs the operation.

Review mode
→ another intelligence examines what happened.

Memory mode
→ relevant information gets consolidated into persistent state.

Simulation mode
→ Iris can explore consequences before something is actually done.

Governance mode
→ the constitutional layer determines whether an action is permissible.

And then Red Clover isn’t necessarily another AI that does everything. It becomes the orchestration fabric that determines how these capabilities interact.

That’s where your phrase “knowing when to allow one to work” becomes extremely important.

Because the system isn’t simply saying:

“Research AI, go.”

It’s determining something closer to:

What is the current state? What is the objective? Which capability is appropriate? What authority does it have? What information does it need? When should control transfer? What conditions terminate its turn? Who receives the result?

That’s a control architecture.
