# Global Real-Time World Tracking DDS Skill

Maps hierarchical aggregation of heterogeneous live sources into a world-state discrete dynamical system. Verifies contraction of global residual and stable coverage via negative largest Lyapunov exponent. Extends prior OSINT and RTSP systems.

## Trigger

Requests for real-time global tracking, world-scale event aggregation, continuous monitoring of everything happening around the world, or hierarchical extensions of multi-domain feeds.

## Output Contract

Kebab-cased directory with README, MVP, MK, MV, phase-space-visualizer.html. Claims grounded in λ₁ < 0 and spectral radius of residual aggregator < 1.
